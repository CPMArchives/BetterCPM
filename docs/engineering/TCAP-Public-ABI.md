# TCAP 1.0 historical design index

TCAP 1.0 was an unreleased design. The implemented engineering candidate is
[TCAP 2.0](TCAP-Direct-ABI.md), with a compact direct-operation interface and
[full-path qualification](TCAP-Direct-Integration-Results.md).

The [transaction design](TCAP-Transaction-ABI-Historical.md) and its original
[wire tables](contracts/tcap-1.0.json) are retained as historical design records.
The subsequent [protocol-template experiment](TCAP-Template-ABI-Historical.md)
was also unreleased and is superseded by the direct interface. Neither is a
runtime compatibility promise or a supported build profile in this change.

Utility migrations and release assignment remain deferred.
