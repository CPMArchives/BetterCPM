# DUMP hexadecimal file viewer

The complete DUMP user reference is now in the [BetterCP/M Utilities Manual](utilities_manual.md#dump-hexadecimal-file-viewer). It covers command options, screen setup, paging, search, prompt editing, original CP/M display, and recovery messages.

Enhanced `/FROM=` starts at the exact byte while preserving aligned columns. `/LEN=` limits the displayed byte count, including partial edge rows; see the manual for fixed-range paging, Go To and Find behavior. `/BARE` rejects `/LEN=`.
