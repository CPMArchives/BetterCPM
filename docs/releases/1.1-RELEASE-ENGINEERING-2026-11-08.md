# BetterCP/M 1.1 release engineering — in progress

No v1.1 tag or release is authorized by this record. The feature scope remains
that of merged PR #665, including TCAP 2.0. Existing 1.0 and 1.0.1 package
folders and archive locks are unchanged.

The release branch adds the eight-asset layout, independent package notices,
Model II System/Utilities selection, four-manual documentation selection with
Model II and TCAP references, and the public TCAP helper/contract material.
`prepare_release_11_media.py` copies qualified System outputs into a separate
packaging area and adds independently inspected blank work media for cpmsim
and Model 4. It does not rebuild or replace the original System images.

All three System builders now select integrated ADM3A/VT52/ANSI TCAP 2.0
carriers. Model 4 startup loads the integrated ADM3A without loading M4SCRN.
Standalone screen modules remain available for separate SCRN/SCX clients.
The TCAP full-path ceilings and zero permanent display reservation are unchanged.

## Demonstrated corrections

- The legacy cpmsim monitor acceptance expected one contiguous escape sequence.
  The integrated renderer emits positioned cells. The check now observes the
  completed editor row and retains memory and complete-unload assertions.
- Plain VER continued to identify development after core 1.0 while the cold
  banner reported Core OS 1.1. The package heading now selects 1.1 independently
  of utility development revision markers, within its original fixed field.
- Model II's release-record validator rejected the engineering TCAP carriers'
  hard-coded version 0.1. The integrated builder now uses registered module
  versions; the independently versioned public service still advertises TCAP 2.0.
- PATH qualification formerly attempted to recreate files already on packaged
  media. It now retains byte-identical packaged inputs and refuses differing
  ones. B is explicitly a scratch fixture disk, avoiding the nearly full
  Utilities volume. The separate paired-media test exercises actual Utilities B.

PASS observations and unverified gates. Source `caf18b38f51d6c7977f30a49dac083db310686c7`
passed cpmsim's 23 construction/lifecycle/install cases, including 57,344-byte
maximum load and exact unload recovery. All three TCAP personalities passed

from the candidate System image. PATH passed 32 commands, including 57,472-byte
rejection. Actual System/Utilities SUBMIT/XSUB pairing passed. Both Utilities
formats passed independent membership/allocation inspection. The pinned runtime

These observations predate the later carrier-version and heading corrections.
They must not be promoted to acceptance of the resulting changed images.
The native Model II release-record failure and the Model 4 source-mutation
refusal are preserved, not reclassified as successful final builds.
