Model 4 installation using the normalized CONFIG binding

Use private writable copies. Keep the original release DMK intact.
This procedure is for the supplied 80-cylinder double-sided 780K SYSTEM layout.

1. Make source.dmk and target.dmk as two separate copies of
   BetterCPM-Distribution-trs80gp-80T-DS-System.dmk. Using a System copy as the
   destination supplies both its 20 KiB reserved area and the support files.
   The supplied 800K Work disk uses a different layout. It is not this target.
2. In trs80gp, mount source.dmk in physical drive 0 and target.dmk in physical
   drive 1. Start Model 4 and wait for the A0 prompt. Physical drive 1 is being
   used for the target rather than the normal primary Utilities disk.
3. The source's default B: binding is the 800K data layout. Select the System
   format by its catalogue display name in the updated CONFIG:

   CONFIG /LOGICAL=B /PHYSICAL=1 /FORMAT="BetterCP/M Model 4 System 780K"

   The message is "Disk configuration changed (until cold boot)."
   CONFIG converts the temporary B: binding to four reserved side-tracks,
   equivalent to the catalogue and boot disk's two cylinders. DIR B: must show the target's System files before proceeding.
4. Export the source system to a named file on the target:

   SYSGEN A: B:INSTALL.SYS

   Wait for "Package exported and verified."
5. Install that package on the same prepared target:

   SYSGEN B:INSTALL.SYS B:

   Verify the destination, then type Y at "Proceed (Y/N)?".
   Wait for "System installed and verified."
6. Quit trs80gp. Mount target.dmk alone in physical drive 0 and cold boot.
   Confirm the banner, DIR A:, CONFIG /SHOW, and RSX LIST. Verify a known file
   that existed on the target before installation.
7. For normal combined use, quit before remounting the installed System as
   physical 0 and Utilities as physical 1. A cold boot restores the normal
   B: 800K data binding. The temporary assignment was not saved as startup defaults.

The qualification used KEEP.TXT as a preservation marker and verified the target filesystem and files. The named-binding behavior is included in the five locked packages, source 30b24a021cc3a90eb725cc3d1760dfe0dc31daa8, with qualification accepted through merge 2842d0eb0732683d9280a38d576c3dba423cb893. See ../releases/non-documentation-lock-1.0/README.md and its exact inventories/qualification references. This documentation edit performs no new install trial.

The installed Model 4 payload has the recorded bootstrap-binding difference at offset 7030 (E0 to A0). It is not a blanket waiver for other differences. The temporary B assignment is not saved as the normal B DATA default.

Historical 35c56a03 CONFIG rejected the named command and used /EDIT=B /OFF=4 /DSM=389 as a workaround. That historical workaround is not the locked release installation procedure. Current CONFIG performs the accepted normalization without changing the on-disk layout.
