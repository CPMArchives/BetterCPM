BetterCP/M 1.3 - Cromemco Z-1 / z80pack

Boot the System disk in A:. Utilities use the same four-drive floppy format.
Mount Utilities-1 in C: and Utilities-2 in D: initially. PATH searches C0: D0:.
Keep HELP/NOAH/FDB overlays with their commands. Swap utility disks as needed.
Use RSX LOAD ANSI (or ADM3A / VT52) for screen applications such as HELP.
Use BYE /Y to exit the emulator.
Hard disks and physical hardware are outside this first emulator release.
