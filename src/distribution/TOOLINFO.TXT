Use a writable work drive with these read-only tools on Utilities B:
  A:
  B:ZSM4 PROGRAM=PROGRAM
  B:LINK PROGRAM[A]
ZSM4 reads PROGRAM.MAC and writes PROGRAM.REL; LINK creates PROGRAM.COM.
Use CSEG for relocatable code; ORG 100H alone can create a 256-byte gap.
